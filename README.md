# Quiz Master v2

## Overview

Quiz Master v2 is a multi-user online examination platform designed to enable administrators and users to manage and participate in quizzes efficiently.

The application provides features such as user authentication, quiz management, scheduling, and asynchronous task handling through a full-stack web architecture.

---

## Features

- User authentication and role-based access.
- Create, manage, and attempt quizzes.
- Schedule quizzes and manage examination timelines.
- REST API-based backend architecture.
- Responsive frontend interface.
- Background task processing using Celery.

## Architecture

The application follows a client-server architecture:

- **Frontend:** Vue.js-based user interface for user interactions.
- **Backend:** Flask REST APIs handling business logic and data processing.
- **Database:** Stores user information, quiz details, and application data.
- **Celery:** Handles asynchronous background tasks.
